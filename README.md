# ComD Team — メンバー管理

株式会社kiCk **Communication Design Team** のメンバー情報をJSON形式で一元管理するリポジトリです。

## ディレクトリ構成

```
ComD-Team/
├── team.json                  # チーム全体インデックス（メンバー一覧）
├── members/                   # メンバー個別ファイル
│   ├── member-001_miyazaki-taro.json
│   └── member-00X_<name>.json
├── projects/                  # プロジェクト情報（任意）
└── schema/
    └── member.schema.json     # メンバーデータのJSONスキーマ定義
```

## メンバーファイルの管理項目

| カテゴリ | 主な項目 |
|---|---|
| **基本情報** | 氏名・役職・在籍ステータス・連絡先・参加日 |
| **スキル** | スキル名・習熟度（1〜5）・カテゴリ |
| **ツール** | 使用ツール・習熟レベル（beginner〜expert） |
| **得意分野** | 専門領域・強み領域 |
| **プロジェクト** | 担当案件・役割・期間・ステータス |
| **目標（OKR）** | 年度目標（O）・主要成果（KR）・進捗 |
| **評価記録** | 期別総合評価・フィードバック・強み・成長領域 |
| **1on1記録** | 日付・サマリー・アクションアイテム・完了状況 |

## 在籍ステータス一覧

| 値 | 意味 |
|---|---|
| `active` | 在籍中 |
| `on_leave` | 休職中 |
| `part_time` | 時短・パートタイム |
| `contractor` | 業務委託 |

## 新メンバーの追加方法

1. `schema/member.schema.json` を参照してJSONを作成
2. `members/member-XXX_<name>.json` として保存
3. `team.json` の `members` 配列にエントリを追加

## スキル習熟度基準

| レベル | 目安 |
|---|---|
| 1 | 学習中・基礎知識あり |
| 2 | 指示・補助があればできる |
| 3 | 独力で標準的な業務ができる |
| 4 | 高品質なアウトプットを安定的に出せる |
| 5 | チーム内エキスパート・他者に教えられる |
