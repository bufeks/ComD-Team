>

## 管理項目

| カテゴリ | 主な項目 |
|---|---|
| **基本情報** | 氏名・役職・在籍ステータス・連絡先・参加日・バックグラウンド |
| **強み・特徴** | 定性的な強み・傾向 |
| **スキル** | スキル名・習熟度（1〜5）・カテゴリ |
| **専門領域** | 得意分野 |
| **CliftonStrengths** | 上位5・上位10資質、傾向サマリー |
| **Talent Analytics** | 診断スコア |
| **ピアフィードバック** | AD・プロデューサー等からのGood / More / 追加コメント |
| **自己評価** | 期別の成果・改善意識・伸びしろ |
| **プロジェクト** | 担当案件・役割・期間 |
| **目標（OKR）** | 年度目標（O）・主要成果（KR）・進捗 |
| **評価記録** | 期別総合評価・フィードバック |
| **1on1ログ** | 日付・メモ（解釈を加えず原文記録）・アクションアイテム |
| **中心人物テーマ** | 「中心人物になる」の個人別翻訳・半年仮テーマ |
| **マネジメントメモ** | 宮崎太郎による自由記述メモ |

## データの時点について

- 評価情報の基準時点：**2025年12月**
- 今後アップデートされる変動情報として扱う
- `data_reference_date` フィールドで各データの時点を管理

## 1on1ログ運用ルール

- メモ内容は解釈を加えず原文ログとして記録する
- 各メンバーファイルの `one_on_ones` 配列に追記していく
- 記録済み：2026年3月分（古橋・佐内・稲垣・坂井）

## 新メンバーの追加方法

1. `schema/member.schema.json` を参照してJSONを作成
2. `members/member-XXX_<name>.json` として保存
3. `team.json` の `members` 配列にエントリを追加

## スキル習熟度基準

| レベル | 目安 |
|---|---|
| 1 | 学習中・基礎知識あり |
| 2 | 指示・補助があればできる |
| 3 | 独力で標準的な業務ができる |
| 4 | 高品質なアウトプットを安定的に出せる |
| 5 | チーム内エキスパート・他者に教えられる |
